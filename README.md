# Al-Hikam Digital Android V1.0.1

Complete Android Studio source project with GitHub Actions APK build.

Changes: system bar inset handling for Android 15, compact side-by-side learning progress, WebView rendering tweaks, centered safe-area launcher icon, and app versionName 1.0.1.

Push entire contents including `.github/workflows/android.yml` to GitHub `main`. Download debug APK from Actions artifacts.

Important: this is source code, not a precompiled APK. Real-device build and performance have not yet been validated. The Android app still uses placeholder ads; AdMob and Google Play Billing are not integrated.
