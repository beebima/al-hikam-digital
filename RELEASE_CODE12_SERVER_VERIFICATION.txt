PENTING — BELUM AKTIF END-TO-END:
Cloud Run saat ini REQUIRE AUTHENTICATION (IAM). Permintaan Android ke /verify akan ditolak
oleh Cloud Run IAM (401/403) hingga ada mekanisme autentikasi aplikasi yang sesuai.
JANGAN membuka server ke publik tanpa mitigasi penyalahgunaan (Play Integrity,
rate limiting/quotas, dan monitoring biaya), karena purchase token bersifat sensitif.
Kode backend hanya memvalidasi token ke Google Play, BELUM memasang RTDN, Firestore,
atau kebijakan refund eksternal. Refund tanpa revoke harus dikaji berdasarkan
purchaseState dan refundableQuantity; tidak semua refund muncul di Voided Purchases.
GET / tetap menyediakan diagnosis Voided Purchases ringkas tanpa token.

Cara deploy backend: Cloud Run > Source > Edit source: replace index.js dan package.json
sesuai file backend-cloud-run, function entry point helloHttp, Save and redeploy.
Tes GET privat Cloud Shell memakai gcloud auth print-identity-token seperti sebelumnya.

Pastikan verifikasi server selesai dan keamanan endpoint disiapkan sebelum membuat
klaim bahwa refund otomatis sudah berfungsi di aplikasi produksi.
